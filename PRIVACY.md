# MidiVoci Privacy Policy

**Last updated:** June 5, 2026

MidiVoci does not collect, store, or transmit any personal data.

## What the app does

MidiVoci is a music playback and score-viewing application for MIDI and MusicXML files. It runs entirely on your device.

## Network Access

The app makes the following network requests, all initiated by your actions:

- **Wikipedia API** — When you select a composer or musical work, the app fetches a Wikipedia summary if available. This is done via the public Wikipedia API.
- **IMSLP** — Links to imslp.org are provided for sheet music sources. You choose whether to follow these links.

No analytics, crash reporting, telemetry, or advertising networks are used.

## File Access

The app can read MIDI and MusicXML files that you explicitly select via the system file picker. These files are processed locally and are never uploaded anywhere.

## Data Storage

The app stores only user preferences in local storage (theme choice, language, UI panel states). This data never leaves your device.

## Third-Party Services

The app links to external services (Wikipedia, IMSLP, PayPal for donations) but does not share any data with them automatically.
